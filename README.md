# Reservas de clases de artes marciales

## Descripción

- Aplicación web para gestionar las reservas de un gimnasio de artes marciales
- y deportes de combate

- Los usuarios podrán iniciar sesión, consultar las clases en un calendario semanal y reservar plazas para las diferentes clases. El calendario permitirá consultar las semanas hasta el último día del mes actual

- Antes de guardar una reserva, la aplicación pedirá confirmación al usuario.
- Después mostrará si se ha realizado la reserva correctamente

- El gimnasio será responsable de dar de alta a los usuarios

## Disciplinas

- Boxeo
- Muay Thai
- Bjj
- MMA

## Reglas de reserva

- Cada clase tendrá una capacidad para 30 usuarios
- Todas las clases tendrán una duración de 90 minutos
- Será necesario iniciar sesión para realizar una reserva
- Podrá haber clases de distintas disciplinas al mismo tiempo
- Un usuario podrá reservar varias clases el mismo día, siempre y cuando no se solapen sus horarios
- Un alumno no podrá reservar dos veces la misma clase
- No se admitirán reservas cuando las 30 plazas estén ocupadas
- El usuario podrá cancelar una reserva antes de iniciar la clase
- Una cancelación liberará la plaza para otro usuario

## Tecnologías previstas

- React y TypeScript para la interfaz
- Java y Spring Boot para el servidor y las reglas del negocio
- PostgreSQL para almacenar los datos
- Git y GitHub para gestionar y publicar el historial del proyecto
